# 全屏框选内联标注实施计划

> **执行说明：** 按任务逐项实现，每项先增加失败用例，再实现最小改动并运行相应用例。

**目标：** 将框选、九种标注工具、颜色选择和截图确认放在同一全屏窗口中，选区显示原屏幕像素。

**架构：** 扩展 `ScreenCapture.RegionOverlay`，让它在屏幕快照上绘制暗色选区外遮罩、选区和标注，并在同一窗体内承载工具栏。框选确认后由遮罩返回合成后的位图，`App` 沿用现有框选截图保存与强制挂绳流程；其他截图仍使用原流程。

**技术栈：** C#、WinForms、System.Drawing、现有截图流水线和桌面测试。

## 全局约束

- 选区内显示遮罩出现前采集的原始屏幕像素，只有选区外叠加半透明暗色。
- 标注确认前不写入截图文件、不导入图绳。
- 点叉、Esc 或关闭窗口均丢弃当前截图；点勾保存为 PNG 并强制挂到图绳。
- 颜色选择包含常用色块和自定义颜色；修改颜色只影响后续标注。
- 保留九种工具、撤销、保存到本地和已配置工具快捷键；普通编辑器及其他截图路径不变。
- 不恢复长截图，不增加 OCR、翻译、解释、贴图、带壳截图或全局热键。

### 任务 1：定义可测试的选区遮罩和合成边界

**文件：**

- 修改：`tests/DesktopTests.cs`

**接口：**
- 新增内部纯绘制方法 `ScreenCapture.RenderRegionFrame(Bitmap desktop, Rectangle desktopBounds, Rectangle selection, Color shade, float opacity)`，返回与桌面快照尺寸一致的新位图；选区外叠加暗色，选区内逐像素保持不变。空选区表示整屏压暗。
- 新增内部方法 `ScreenCapture.CropRegion(Bitmap desktop, Rectangle desktopBounds, Rectangle selection)`，将桌面坐标转换为快照本地坐标并裁切；裁切后的宽或高小于 2 像素时抛出 `ArgumentOutOfRangeException`。

### 任务 2：让框选层保持打开并直接提供标注工具

**文件：**
- 修改：`src/ScreenCapture.cs`
- 新建：`src/RegionOverlay.cs`
- 修改：`tests/DesktopTests.cs`

**接口：**
- `ScreenCapture.Region()` 在用户确认后返回合成完成的 `Bitmap`；取消或关闭返回 `null`。
- `RegionOverlay` 是可由桌面测试直接构造的 `internal sealed class`，构造签名为 `RegionOverlay(Bitmap desktop, Rectangle desktopBounds)`；生产默认路径在显示遮罩前获取整个虚拟桌面快照。
- `RegionOverlay.SetSelection(Rectangle)` 锁定桌面坐标选区并保留窗体；`RegionOverlay.ConfirmSelection()` 返回合成的裁切 `Bitmap`；`RegionOverlay.CancelSelection()` 清除结果并结束窗体。
- `RegionOverlay.ActiveTool` 与 `RegionOverlay.CurrentColor` 表示当前标注工具和颜色；`SetTool(string)`, `SetColor(Color)` 和 `Undo()` 由工具条事件及快捷键共用。

- [ ] **步骤 1：先添加失败测试。** 用注入的小型桌面位图直接构造 `RegionOverlay`，验证 `SetSelection` 后窗体状态仍可确认、活动工具和颜色可读写、撤销会移除最近一条绘制操作、取消不返回图像；验证自定义选区上的工具栏矩形位置被限制在虚拟桌面边界内。
- [ ] **步骤 2：运行测试确认失败。** 预期项目因 `RegionOverlay` 类型和操作接口尚不存在而无法编译。
- [ ] **步骤 3：新建 `RegionOverlay.cs`。** 添加注入桌面快照的构造器、默认生产构造器、选区状态、结果位图生命周期和确认/取消方法；默认构造器在 `ShowDialog` 前调用屏幕复制方法。
- [ ] **步骤 4：实现绘制层。** `OnPaint` 按 1:1 像素绘制快照，对选区外绘制暗遮罩，在选区内按顺序绘制标注预览；鼠标拖动仅在初始框选态更新选区，选区锁定后输入交由工具操作。
- [ ] **步骤 5：实现横向工具条。** 创建工具按钮、八个常用色块、自定义颜色按钮、撤销、保存、叉号和勾号；位置优先选区上方，必要时下移并裁在桌面范围内。
- [ ] **步骤 6：实现九种标注操作与快捷键。** 操作保存为内存历史并在重绘时重放；矩形/椭圆/箭头/画笔按当前颜色绘制，马赛克对选区截图像素化，文字使用内联文本框，序号递增，高亮半透明填充，取色从底图采样。支持 1 至 9、已保存自定义热键、Ctrl+Z、Enter 确认、Esc 取消。
- [ ] **步骤 7：实现本地 PNG 保存。** 从原始选区和标注历史生成完整分辨率 PNG，经保存对话框写盘；成功或取消后清除保存忙碌状态但保持标注窗体打开。
- [ ] **步骤 8：运行桌面测试。** 确认同窗体操作、颜色、撤销、确认、取消、快捷键、工具栏边界及保存后可继续使用。
