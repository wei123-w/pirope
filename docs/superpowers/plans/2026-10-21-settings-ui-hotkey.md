# 设置界面美化与快捷键录入实施计划

**目标：** 将设置窗口调整为与图绳其他界面一致的浅色卡片布局，并让快捷键框聚焦后能直接录入组合键。

**架构：** 保持现有设置窗口和保存逻辑，只改设置窗口的布局与控件状态反馈。快捷键仍由窗口级按键预览事件捕获，并保留修饰键、空值、重复值校验。

**技术栈：** C#、WPF、项目现有 `LightTheme` 样式与构建脚本。

## 全局约束

- 保留常规、快捷键、截图页的现有功能和状态字段。
- 快捷键至少包含 Ctrl、Alt、Shift、Win 中的一项；Esc 或退格清空。
- 不增加外部依赖。
